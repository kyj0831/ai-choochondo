# AI 추천도 진단

회사·개인 브랜드·가게·강사의 AI 검색·추천 노출을 5축으로 진단하고,
개선 액션과 복붙 문안까지 제공하는 GEO/AEO 웹서비스입니다.

## 실행 방법

### 가장 쉬운 방법 (macOS)

Finder에서 이 폴더의 **`start.command`를 더블클릭**하세요.
(최초 실행 시 "확인되지 않은 개발자" 경고가 나오면: 우클릭 → 열기)

### 터미널로 실행

```bash
cd "이 폴더 경로"
npm install        # 최초 1회
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## LLM 키 설정 (선택)

**키가 없어도 바로 동작합니다** — 이때는 데모(목업) 모드로, 질문 생성·판정·리포트가
그럴듯한 샘플 로직으로 채워집니다.

실제 AI 분석을 쓰려면 `.env.local` 파일에 **둘 중 아무 키나 하나** 넣으세요:

| 키 | 발급처 |
|---|---|
| `OPENAI_API_KEY=sk-...` | https://platform.openai.com/api-keys |
| `ANTHROPIC_API_KEY=sk-ant-...` | https://console.anthropic.com/settings/keys |

키를 넣은 뒤 서버를 재시작하면 자동 감지됩니다.

## 사용 흐름

1. **새 진단** — 이름·유형(개인 브랜드/자영업/기업/전문 서비스)·지역 입력
2. **프로젝트 설정** — 대표 카테고리, 공식 채널, 사실 기준선(Ground Truth) 입력
3. **질문 세트** — 자동 생성된 직접 검색/범주형 추천/설명 검증 질문 검토·편집
4. **증거 수집** — 각 질문을 ChatGPT·Perplexity 등에 직접 물어보고 답변을 붙여넣기
5. **분석 실행** — 5축 점수·등급·핵심 발견·우선 액션 5개·복붙 문안 리포트 생성
6. **재진단** — 채널 수정 후 동일 조건으로 재분석, 전회 대비 점수 변화 확인

## BIBL — 레퍼런스 보관함 (/bibl)

잘 터진 영상을 찾고(영상 찾기), 저장하고(내 보관함), 왜 잘됐는지 해부하고, 내 주제로 바꿔 쓰는(내 버전 만들기) 서비스입니다.
일하며 아이 키우며 유튜브를 하는, 썸네일·제목 "감"이 아직 없는 사람을 위해 만들었습니다.

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 영상 찾기 | `/bibl` | 아래 "영상 찾기" 기능 + 결과마다 **＋ 레퍼 저장** (보드·배운 점 한 줄) |
| 내 보관함 | `/bibl/library` | 보드별 정리, 제목 유형·검색 필터, 썸네일 무드보드 보기, 다른 기기용 열쇠 링크 |
| 레퍼 상세 | `/bibl/ref/{id}` | 썸네일·제목 해부, 배운 점·태그, **내 버전 만들기**(제목 5안·썸네일 3안) |

- 회원가입이 없습니다. 처음 저장할 때 브라우저에 보관함 열쇠(쿠키)가 생기고, 휴대폰에서는 보관함의 "열쇠 링크"로 엽니다.
- AI 키(`OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY`)가 있으면 썸네일 이미지까지 읽어 해부하고, 제목·썸네일 안도 AI가 씁니다.
  키가 없으면 제목 규칙과 숫자 지표로 해부하고, 템플릿으로 안을 만듭니다.
- 샘플(데모) 영상은 저장할 수 없습니다. `YOUTUBE_API_KEY`를 넣고 실제 영상을 검색하세요.
- 같은 조건의 검색은 6시간 동안 다시 YouTube에 묻지 않습니다(쿼터 절약).

## 영상 찾기 (/bibl)

유튜브에서 **구독자 수에 비해, 그 채널 평소보다 잘 터진 영상**을 찾는 화면입니다. `/bibl`에서 엽니다(예전 주소 `/video-search`는 자동으로 넘어갑니다).

- 키워드 검색 또는 🔥 핫 비디오(국가별 인기 급상승)
- 영상마다 3개 등급(Great·Good·Normal·Bad·Worst)
  - **성과도** = 조회수 ÷ 구독자
  - **기여도** = 조회수 ÷ 채널 영상 1개당 평균 조회수
  - **노출확률(추정)** = 하루 평균 조회수 ÷ 채널 평소 속도
- 조회수·구독자·등급·길이·게시일 정렬, 기간·길이·구독자 범위 필터
- 카드/표 보기, 영상·채널 제거, CSV(엑셀) 저장, 검색 내역

`.env.local`에 `YOUTUBE_API_KEY=`를 넣어야 실제 검색이 됩니다. 키가 없으면 샘플 데이터로 동작합니다.
무료 쿼터는 하루 10,000 단위이고, 키워드 검색 50개에 약 102 단위가 듭니다(하루 약 90회).

## 문제 해결

- **"Cannot find module" / 500 에러 / 화면이 안 뜸**: 빌드 캐시 손상입니다.
  서버를 끄고 `.next` 폴더를 삭제한 뒤 `npm run dev`를 다시 실행하세요.
- **포트 3000이 이미 사용 중**: `PORT=3001 npm run dev`로 다른 포트 사용
- **better-sqlite3 오류**: `npm rebuild better-sqlite3` 실행
- **데이터 초기화**: `data/app.sqlite` 파일 삭제 후 서버 재시작
