# 미팅 예약 (/book)

내 Google 캘린더의 **빈 시간만** 골라 외부인에게 보여주고, 예약하면
캘린더에 일정(+ Google Meet 링크)을 만들고 상대에게 초대 메일을 보냅니다.

- 주소: `http://localhost:3000/book`
- Google을 연결하기 전에는 **데모 모드**로 동작합니다(예시 일정, 실제 초대 없음).

## 동작 방식

1. 근무 요일·시간(기본: 평일 10:30~18:30, 서울 기준)을 30분 단위 슬롯으로 자릅니다.
2. Google Calendar `freeBusy` API로 바쁜 시간을 읽어 겹치는 슬롯을 지웁니다.
   (일정 제목·내용은 읽지 않고 "바쁨" 여부만 봅니다)
3. 방문자는 자기 시간대로 바뀐 시각을 보고 고릅니다.
4. 예약 직전에 한 번 더 비어 있는지 확인하고(이중 예약 방지), 일정을 만듭니다.

### AI 기능
- **말로 요청하기**: "다음 주 화요일 오후" → 빈 슬롯 중에서 골라 줍니다.
- **일정 제목·아젠다 초안**: 예약자가 쓴 미팅 목적을 읽고 캘린더 일정 제목과 아젠다를 만듭니다.

기존 `OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY`를 그대로 씁니다. 키가 없으면 규칙 기반으로 동작합니다.

## Google 캘린더 연결 (최초 1회, 약 10분)

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고
   **Google Calendar API**를 사용 설정합니다.
2. **OAuth 동의 화면**: 사용자 유형 "외부", 테스트 사용자에 내 Google 계정을 추가합니다.
   > 테스트 상태로 두면 리프레시 토큰이 7일마다 만료됩니다. 계속 쓰려면 "프로덕션으로 게시"하세요
   > (내 계정만 쓰는 용도라 심사 없이 경고 화면만 뜹니다).
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션**을 만들고
   승인된 리디렉션 URI에 아래를 추가합니다.
   - 로컬: `http://localhost:3000/api/book/google/callback`
   - 배포: `https://내도메인/api/book/google/callback`
4. `.env.local`에 넣고 서버를 재시작합니다.
   ```
   GOOGLE_CLIENT_ID=...
   GOOGLE_CLIENT_SECRET=...
   BOOKING_ADMIN_KEY=아무-긴-문자열
   ```
5. 브라우저에서 `/api/book/google/connect?key=아무-긴-문자열` 을 열고 권한을 허용합니다.
   "캘린더 연결 완료"가 뜨면 끝입니다. `/book` 상단의 "데모 모드"가 "예약 가능"으로 바뀝니다.

> `BOOKING_ADMIN_KEY`를 꼭 정하세요. 없으면 "아직 연결 안 된 상태"에서만 연결이 허용되지만,
> 배포 직후 다른 사람이 먼저 연결할 여지를 없애려면 키가 안전합니다.

## 바꿀 수 있는 설정

`.env.local.example`의 "미팅 예약" 블록 참고 — 호스트 이름·직함·회사, 근무 시간, 미팅 길이,
최소 사전 예약 시간, 예약 가능 기간, 앞뒤 버퍼, 오프라인 장소, 함께 확인할 캘린더 목록.

## 기록

예약은 `data/app.sqlite`의 `bookings` 테이블에도 남습니다.
